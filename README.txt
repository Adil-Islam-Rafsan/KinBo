KINBO — FLAT GITHUB UPLOAD VERSION

All website files are intentionally placed in ONE folder so you can upload them
from an iPhone without selecting folders.

IMPORTANT:
1. Upload every file in this package to the ROOT of your KinBo GitHub repository.
2. Do not upload the ZIP itself as the website source; extract it first.
3. Keep filenames unchanged.
4. Set js/config.js -> whatsappNumber to your real WhatsApp number.
5. Update delivery fees in config.js.
6. Replace demo products in products.json and add product photos to the repository root.
   Example: if JSON says "images": ["KB009.jpg"], upload KB009.jpg beside index.html.
7. GitHub Pages must publish from the repository root.

This is a static storefront with WhatsApp order-request checkout. It does not
include a secure order database, admin dashboard, automatic stock reservation,
or online payment gateway. Replace all sample product data and policies before launch.
